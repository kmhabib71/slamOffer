# n8n Setup Instructions

## Starting n8n

1. Open PowerShell
2. Navigate to project directory: `cd "D:\Projects\Grand-offer\slamOffer"`
3. Start n8n: `npx n8n`
4. Wait for message: "Editor is now accessible via: http://localhost:5678/"
5. Open browser: http://localhost:5678

## First Time Setup

1. Create admin account (owner account)
2. Set up basic settings
3. Test first workflow

## Stopping n8n

- Press `Ctrl + C` in the PowerShell window running n8n

## Default Data Location

- Windows: `C:\Users\[USERNAME]\.n8n`
- All workflows, credentials, and settings are stored here
